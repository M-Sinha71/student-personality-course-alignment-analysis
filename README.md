# Student Personality and Course Alignment Analysis

## Overview
This research project analyzes the relationship between student personality traits, learning styles, and course alignment using survey-based data analysis.

The project aims to understand how personality influences:
- Academic satisfaction
- Programming confidence
- Learning behavior
- Problem-solving ability
- Course compatibility

---

## Objectives
- Analyze student learning patterns
- Identify personality-based academic trends
- Study the relationship between MBTI and learning styles
- Perform exploratory data analysis (EDA)
- Generate statistical insights from survey data

---

## Technologies Used
- R Programming
- ggplot2
- Excel / Google Forms
- Statistical Analysis
- Data Visualization

---

## Dataset Information
The dataset contains responses collected from students through Google Forms.

### Features Included
- Student Age
- Course Year
- CGPA
- Learning Style
- MBTI Personality Type
- Academic Satisfaction
- Programming Confidence
- Curiosity for Technology
- Group Learning Preference
- Task Motivation

---

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Missing Value Handling
4. Exploratory Data Analysis
5. Statistical Analysis
6. Visualization
7. Research Findings

---

## Key Insights
- Certain personality traits showed stronger analytical confidence.
- Students with high curiosity for technology demonstrated better engagement.
- Learning styles influenced academic satisfaction levels.
- Personality-course alignment affected programming confidence.
